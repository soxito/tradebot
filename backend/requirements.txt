# Face Vision (GPU-accelerated)
# Install:  bash scripts/setup-face-vision.sh
# • mediapipe — FaceMesh 478 landmarks, GPU via CUDA/Metal (macOS)
#   github.com/google-ai-edge/mediapipe  (36k ⭐)
# • face_recognition — dlib face identity embeddings
#   github.com/ageitgey/face_recognition  (53k ⭐)
# • opencv-python-headless — frame decoding, no GUI deps
# NOTE: these are OPTIONAL and intentionally NOT installed by the core
# `pip install -r requirements.txt`. `face_recognition` pulls in `dlib`, which
# has no prebuilt Windows wheel and needs CMake + a C++ toolchain to compile —
# on a fresh Windows box that breaks the whole install. The vision endpoints
# (backend/app/api/vision.py) import these lazily, so the backend runs fine
# without them. Enable face-vision explicitly with:
#     bash scripts/setup-face-vision.sh
# mediapipe>=0.10.9
# opencv-python-headless>=4.9.0
# face_recognition>=1.3.0
